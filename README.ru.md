# Maos Record — руководство пользователя

[English version](README.en.md) · [Главная страница](README.md) · [Скачать последнюю версию](../../releases/latest)

Maos Record — нативная программа записи экрана для Intel Mac с macOS Catalina 10.15 и новее. Она записывает выбранный монитор в MP4 и может добавить звук и камеру поверх изображения.

## Установка

1. Откройте **[GitHub Releases](../../releases/latest)**.
2. Скачайте `MaosRec-macOS-10.15-Intel.dmg`.
3. Откройте DMG и перетащите **Maos Record.app** на ярлык **Applications**.
4. Откройте папку «Программы», нажмите **Maos Record** правой кнопкой, выберите **Открыть** и подтвердите запуск.

Дополнительное подтверждение требуется потому, что публичная сборка подписана ad-hoc. Если macOS не показывает кнопку «Открыть», один раз выполните в Терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/Maos Record.app"
```

Используйте эту команду только для приложения с официальной страницы Releases проекта. Контрольную сумму файла можно сравнить с `SHA256SUMS.txt`.

## Разрешения при первом запуске

Откройте **Системные настройки → Защита и безопасность → Конфиденциальность** и разрешите:

- **Запись экрана** — требуется всегда;
- **Камера** — требуется только для камеры поверх записи;
- **Микрофон** — требуется только при включённом звуке.

После выдачи разрешения на запись экрана перезапустите Maos Record.

## Запись

1. Выберите монитор в разделе «Экран».
2. Включите или отключите камеру.
3. Выберите положение и размер камеры.
4. Включите или отключите звук и выберите входное устройство.
5. В настройках выберите качество и папку сохранения.
6. Нажмите **Начать запись**.
7. После завершения нажмите **Остановить запись**.

По умолчанию используется профиль «Баланс» — до 720p и 15 кадров/с. Для Mac с 2 ГБ RAM или очень слабым процессором выберите «Экономное — 540p, 12 кадров/с». Режим 720p/30 кадров требует больше ресурсов.

## Звук

Maos Record записывает выбранный аудиовход, обычно встроенный микрофон. Catalina не даёт обычным приложениям прямой доступ к системному звуку. Для записи звука приложений установите доверенное виртуальное аудиоустройство и выберите его в Maos Record.

## Автоматические обновления

Maos Record проверяет [GitHub Releases](../../releases/latest) после запуска и каждые шесть часов, если автоматическая проверка включена. При наличии новой версии приложение может:

1. скачать ZIP из релиза;
2. проверить его по `SHA256SUMS.txt`;
3. проверить идентификатор, версию и подпись приложения;
4. заменить установленную копию и перезапуститься.

Перед установкой обновления остановите запись. Maos Record должен быть запущен из папки «Программы» или другой доступной для записи локальной папки, а не непосредственно из DMG.

## Удаление

Закройте Maos Record и переместите приложение из папки «Программы» в Корзину. Для удаления настроек выполните:

```bash
defaults delete com.maosrec.app
```

Записанные MP4-файлы автоматически не удаляются.
